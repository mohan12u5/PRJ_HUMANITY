# Humanity Brand Web App

A polished clothing brand website built with Next.js and designed for Vercel deployment.

## Features
- Rich landing page with premium-style UI
- Product highlights and brand story section
- Contact form with backend API route
- Ready to deploy on Vercel

## Getting started
1. Install dependencies with `npm install`
2. Run locally with `npm run dev`
3. Replace the placeholder brand name and logo text with your real branding

## Deploy to Vercel
1. Push this folder to GitHub
2. Import the repository in Vercel
3. Deploy
